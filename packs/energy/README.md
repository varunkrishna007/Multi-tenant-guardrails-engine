# The energy pack (draft thresholds)

See [docs/m4-08-domain-packs.md](../../docs/m4-08-domain-packs.md). `pack.json` is the catalog
source document, `golden.jsonl` is generated by `build_golden.py` (do not edit it by hand), and
every threshold is provisional until the M4-01 calibration runs on the real API.

## Version 2

`pack.json` is **@1** and never changes (the catalog is append-only). `pack.v2.json` is **@2**: thresholds from
the 2026-11-18 live calibration and three overlap rewordings, derived by `python -m packs.make_v2`.
See [docs/m4-08-packs-v2.md](../../docs/m4-08-packs-v2.md).

## Latest version

`pack.v3.json` is **@3**: the re-measured thresholds of the two reworded rules (2026-11-19). Every value is provisional; earlier versions never change. Derived by `python -m packs.derive_versions`. See [docs/m4-08-m5-04-pack-versions-2026-11-19.md](../../docs/m4-08-m5-04-pack-versions-2026-11-19.md).
